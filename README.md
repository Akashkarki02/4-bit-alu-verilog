# 4-bit-alu-verilog
4-bit Arithmetic Logic Unit designed and verified using Verilog HDL.
## Simulation Waveform

The 4-bit ALU was simulated using EDA Playground and verified using EPWave.

The waveform demonstrates the transitions of the ALU inputs, operation select signals, and output during different test cases.
